床① ハイブリッド合成床 — メタノール合成 / RWGS / 脱水

① メタノール合成 (MS) model = KOGAS

\[ \ce{CO2 + 3H2 <=> CH3OH + H2O} \]
速度式（分圧 bar 基準）
\[ r_\mathrm{MS} = \frac{k_1\,p_\mathrm{H_2}\,p_\mathrm{CO_2}\left[\,1 - \dfrac{1}{K_\mathrm{eq1}}\dfrac{p_\mathrm{CH_3OH}\,p_\mathrm{H_2O}}{p_\mathrm{CO_2}\,p_\mathrm{H_2}^{3}}\right]}{\mathrm{DEN}^{3}}\times\frac{1000}{3600} \]
\[ \mathrm{DEN} = 1 + K_2\frac{p_\mathrm{H_2O}}{p_\mathrm{H_2}} + K_3\sqrt{p_\mathrm{H_2}} + K_4\,p_\mathrm{H_2O} \]
パラメータ  \(\kappa = A\exp(B/RT)\)

③ メタノール脱水 (MD) model = ZSM5（Ortega 2018 LHHW）

\[ \ce{2 CH3OH <=> CH3OCH3 + H2O} \]
速度式 — modified Klusáček & Schneider（解離吸着＋表面反応律速・水阻害・分圧 bar 基準）
\[ r_\mathrm{MeOH} = \frac{k\,K_M\,p_M\left(1 - \dfrac{p_D\,p_W}{p_M^{2}\,K_\mathrm{eq3}}\right)}{\left(1 + 2\sqrt{K_M\,p_M} + K_W\,p_W\right)^{2}}, \qquad r_\mathrm{MD} = \tfrac{1}{2}\,r_\mathrm{MeOH} \]
分母のメタノール項は \(2\sqrt{K_M\,p_M}\)（解離吸着の平方根依存）。反応次数 \(n_M = 1 - 2\sqrt{K_M p_M}/\mathrm{DEN}\) が論文の \(n_M = 0.07\text{–}0.45\) と一致（線形 \(2K_M p_M\) だと \(n_M<0\) で矛盾）。水項は線形（Eq.21 \(n_W = -2K_W p_W/\mathrm{DEN}\) で確認）。
パラメータ
\[ k = k_\mathrm{T0}\exp\!\left[-\frac{E_\mathrm{app}}{R}\!\left(\frac1T-\frac1{T_0}\right)\right], \qquad K_i = \exp\!\frac{\Delta S^\circ_i}{R}\,\exp\!\left(-\frac{\Delta H^\circ_i}{RT}\right) \]

床② H-MOR カルボニル化床

④ カルボニル化 model = DTU-Cheung2007-2

\[ \ce{CH3OCH3 + CO -> CH3COOCH3} \]
（DME + CO → 酢酸メチル）
速度式（per mol Al。CO 一次・DME 零次・MA 阻害）
\[ r_\mathrm{MA} = \frac{k_1\,p_\mathrm{CO}}{1 + K_2\,p_\mathrm{MA} + K_3\,p_\mathrm{MA}/p_\mathrm{DME}}\;f_\mathrm{reg}(p_\mathrm{DME})\;\times\;\rho_\mathrm{acid} \]
\[ f_\mathrm{reg} = \frac{K_\mathrm{DME}\,p_\mathrm{DME}}{1 + K_\mathrm{DME}\,p_\mathrm{DME}}, \qquad K_\mathrm{DME} = 10^{5}\ \mathrm{bar^{-1}} \]
（DME 枯渇で速度 → 0 の正則化）
パラメータ  （438 K 基準の van't Hoff）
\[ x(T) = x(438)\exp\!\left[-\frac{E}{R}\!\left(\frac1T-\frac1{438}\right)\right] \]
