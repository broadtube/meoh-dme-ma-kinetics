tandem_sty_stack_zsm5 — 反応式・速度式・パラメータ・出典

単管タンデム（ハイブリッド合成床 → H-MOR カルボニル化床）で計算される全反応。 examples/fig_tandem_sty_stack_zsm5.py が使用するモデルに対応。

R = 8.314 J·mol⁻¹·K⁻¹。分圧 p は bar。速度はすべて mol·kg⁻¹·s⁻¹ に統一（native 単位からの換算係数を各所に明記）。「値@250℃」は本条件での定数値。
床① ハイブリッド合成床 — メタノール合成 / RWGS / 脱水

① メタノール合成 (MS) model = KOGAS

CO₂ + 3 H₂ ⇌ CH₃OH + H₂O
速度式（分圧 bar 基準）
rMS = k₁·pH₂·pCO₂·[ 1 − (1/Keq1)·(pCH₃OH·pH₂O)/(pCO₂·pH₂³) ] / DEN³  × (1000/3600)
DEN = 1 + K₂·(pH₂O/pH₂) + K₃·√pH₂ + K₄·pH₂O
パラメータ  κ = A·exp(B/RT)

③ メタノール脱水 (MD) model = ZSM5（Ortega 2018 LHHW）

2 CH₃OH ⇌ CH₃OCH₃ + H₂O
速度式 — modified Klusáček & Schneider（解離吸着＋表面反応律速・水阻害・分圧 bar 基準）
rMeOH = k·KM·pM·( 1 − pD·pW/(pM²·Keq3) ) / ( 1 + 2·√(KM·pM) + KW·pW )²
rMD = rMeOH / 2   （量論 2 MeOH → DME）
分母のメタノール項は 2·√(KM·pM)（解離吸着の平方根依存）。反応次数 nM=1−2√(KMpM)/DEN が論文の nM=0.07–0.45 と一致（線形 2KMpM だと nM<0 で矛盾）。水項は線形（Eq.21 nW=−2KWpW/DEN で確認）。

④ カルボニル化 model = DTU-Cheung2007-2

CH₃OCH₃ + CO → CH₃COOCH₃  （DME + CO → 酢酸メチル）
速度式（per mol Al。CO 一次・DME 零次・MA 阻害）
rMA = k₁·pCO / ( 1 + K₂·pMA + K₃·pMA/pDME ) · freg(pDME)  × 酸点密度
freg = KDME·pDME / (1 + KDME·pDME),  KDME = 10⁵ bar⁻¹  （DME 枯渇で速度→0 の正則化）
